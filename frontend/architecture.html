システムアーキテクチャ

本サイトはレンタルサーバーや常時稼働インスタンスを一切使用せず、AWSのサーバーレス・マネージドサービスのみで構成しています。 年間コスト約1,500円での運用を実現しながら、高パフォーマンス・高セキュリティを両立しています。

設計のポイント

1. 静的配信層 ― S3 + CloudFront + OAC

S3バケットはパブリックアクセスを完全遮断し、CloudFrontからのアクセスのみをOAC（Origin Access Control）で許可。 CloudFrontのエッジキャッシュにより世界中から高速アクセスが可能で、S3への直接アクセスを排除することでセキュリティを強化しています。

2. ドメイン・SSL/TLS ― Route 53 + ACM（クロスアカウント構成）

Route 53のホストゾーンは別AWSアカウントで管理しており、Terraformのassume_roleを使ったクロスアカウント構成でDNSレコードを自動作成。 ACM証明書はCloudFront要件に合わせus-east-1で発行し、DNS検証も自動化しています。

3. サーバーレスAPI ― API Gateway + Lambda + SES

お問い合わせフォームのバックエンドはAPI Gateway（HTTP API）+ Lambda（Python 3.12）+ SESで構成。 サーバーの常時稼働が不要なため、リクエスト発生時のみ課金される極めて低コストな運用を実現しています。

4. IaC ― Terraform（マルチプロバイダ・リモートステート）

全リソース（S3・CloudFront・Route 53・ACM・API Gateway・Lambda・SES・IAM・ECR・DynamoDB・CloudWatch）をTerraformで定義。 ステートファイルはS3に保存し、DynamoDBによる排他ロックとPITRでステートを保護しています。

5. CI/CD ― GitHub Actions（OIDC認証）

フロントエンドはfrontend/配下の変更をトリガーにS3同期とCloudFrontキャッシュ削除を自動実行。 バックエンドはGoのビルド・テスト後にDockerイメージをECRへプッシュ。 AWS認証はOIDCによるシークレットレス認証を採用しています。
