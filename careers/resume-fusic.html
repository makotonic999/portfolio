■ 職務要約

AWS環境の「設計・構築・IaC・CI/CD」を、実務の運用改善と個人開発の両面で手を動かして実践しているインフラエンジニアです。決められた構成をなぞるのではなく、要件・制約・運用性・コストを踏まえて構成を自ら選定し、Terraform でコード化・再現可能にすることを得意としています。

インフラ実務は約3年、うち AWS 実務は約2年。閉域網・最小権限といった厳格なセキュリティ要件下の官公庁向け AWS 環境で、手動運用のレガシー構成に対し、AWS サービスを選定して自動化方式を設計・実装・検証・本番導入し、運用工数とヒューマンエラーを削減してきました。

実務で IaC・Git が未導入という制約に対しては、個人開発で Terraform（マルチプロバイダ／クロスアカウント／リモートステート）、GitHub Actions、OIDC 認証によるシークレットレス CI/CD、3層アーキテクチャの IaC 化と環境分離、ECS Fargate / コンテナ移行の検証までを自ら設計・実装し、GitHub で公開・運用しています。要件定義 → アーキテクチャ設計 → AWS サービス選定 → セキュリティ設計 → IaC 設計 → CI/CD 設計 → コスト最適化 → 運用までを、一連の設計・構築経験として反復しています。

「運用現場で培った壊れにくい設計の勘所」と「IaC / CI/CD を実際に設計・実装できる実装力」、そして体系的裏付けとしての AWS 認定 Solutions Architect – Professional を掛け合わせ、クラウド導入支援の設計・構築フェーズで即戦力に近い立ち上がりを目指します。

■ 個人開発・設計実績（手を動かした設計・構築の実体）

実務での Git・IaC 未導入という制約に対し、AWS アーキテクチャを自ら設計し Terraform で実装・運用している環境を継続的に構築・公開しています。コードはすべて GitHub で公開しており、設計意図・判断の経緯まで追跡できます。

① AWS 3層アーキテクチャの IaC 化と環境を意識した構成管理

  • VPC・パブリック/プライベートサブネット・ALB・EC2・RDS のマルチAZ 3層構成を Terraform で設計・コード化。environments/ 配下で環境を分離する構成とし、再現性のあるインフラ管理を実践。
  • 問い合わせ処理のバックエンドを Go でコンテナ実装し、Docker マルチステージ → ECR → ECS（Fargate）/ Kubernetes への移行・稼働検証を実施。
  • 個人開発においても直接 main へ push せず、Issue 起票・ブランチ・自己 Pull Request による差分レビューを徹底し、GitHub Flow 準拠の再現性ある開発プロセスを運用。
Terraform（マルチプロバイダ／クロスアカウント／リモートステート） / Go / Docker（マルチステージ） / ECR / ECS Fargate / Kubernetes（検証） / VPC / ALB / EC2 / RDS / IAM

② クロスアカウント Terraform ＋ OIDC シークレットレス CI/CD（技術メディア DIVE の配信基盤）

公開サイト: dive.okada-chikuro-kougyousyo.com ／ ソース: github.com/makotonic999/DIVE

  • クロスアカウント構成の設計・実装：リソース用アカウントと DNS（Route 53）管理アカウントを分離し、複数プロバイダ ＋ assume_role でインフラと DNS を一元コード管理。ステートは S3 リモートバックエンドで排他制御。
  • OIDC 認証によるシークレットレス CI/CD の設計・構築：GitHub Actions から OIDC で IAM ロールを引き受け、長期アクセスキーを持たずに「Terraform apply → ビルド → S3 同期 → CloudFront 無効化」を自動化。CI 用ロールは最小権限、IAM 管理はステート分離で権限昇格リスクを抑制。
  • サーバーレス静的配信基盤：Astro + MDX を S3 + CloudFront + OAC で配信。S3 パブリックアクセスを完全遮断し CloudFront 経由のみに限定。常時稼働サーバーを持たない低コスト構成。
Terraform / GitHub Actions（OIDC認証） / Astro / MDX / AWS (S3, CloudFront, OAC, Route 53, ACM, API Gateway, Lambda, SES, CloudWatch, SNS, ECR, IAM)
